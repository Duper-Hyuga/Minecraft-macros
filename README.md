# Game Macros Collection

A collection of automation macros for minecraft made by me, featuring shield breaker, anchor macro, auto pearl, and crystal placement macros.(it was made just for fun in python as external program and really shouldn't be used since it is unstable and works outside of game and doesnt really register what is happening in game)

##  Disclaimer

**These macros are for educational purposes only.** Using automation macros in games may violate the game's Terms of Service. Use at your own risk. The author is not responsible for any consequences, including account bans or penalties.

##  Features

| Macro | Description | Default Hotkey |
|-------|-------------|----------------|
| **Shield Breaker** | Single-cycle shield breaking combo | `X` |
| **Anchor Macro** | Toggle-able anchor placement loop | `R` |
| **Auto Pearl** | Single pearl usage with middle click | `Middle Mouse` |
| **Crystal Macro** | Crystal placement + Obsidian placement toggle | `X` (crystal) / `Y` (obsidian) |

##  Requirements

- Python 3.8 or higher
- Windows OS (keyboard library works best on Windows)
- Administrator/root privileges (for some keyboard inputs)
